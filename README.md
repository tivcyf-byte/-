# Президент (черновик): клон для Android

Рабочее название. Этап M0/M1 по `replica/architecture.md`: каркас, тема, навигация, главный экран.

## Что здесь
- `app/src/main/java/com/example/sim/engine` : правила игры, чистый Kotlin без Android
- `.../data` : слой данных (пока в памяти) и ViewModel с игровым циклом
- `.../nav` : маршруты, список экранов S01-S40, корневой Scaffold
- `.../ui/theme`, `.../ui/components` : дизайн-система из `replica/design`
- `.../ui/screens` : S05 (главный экран), хаб раздела, заглушка
- `app/src/test` : тесты движка (JUnit)
- `.github/workflows/build.yml` : тесты и сборка debug APK в GitHub Actions

## Как собрать без компьютера
1. Загрузи содержимое папки в GitHub-репозиторий (так же, как ты делаешь с CapitalTrack).
2. Открой вкладку Actions: запустится шаг Build. Gradle Wrapper не нужен.
3. Когда шаг зелёный, скачай артефакт `app-debug` и установи APK на телефон.
4. Если шаг красный, скачай артефакт `test-report` или открой лог шага и пришли мне текст первой ошибки.

## Что проверить на телефоне
- Дата и казна стоят на паузе. Нажми 1x: дата растёт раз в секунду, казна увеличивается на прирост за день.
- Переключи скорость, сверни приложение (оно уйдёт на паузу), вернись.
- Нижние вкладки и список «Разделы» открывают заглушки с кнопкой «Назад».
- Масштаб шрифта 1,3x и 2,0x, язык English, TalkBack.

Код не компилировался при написании: если сборка упадёт, чаще всего виноваты версии в `gradle/libs.versions.toml`.
